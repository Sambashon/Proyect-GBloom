# 🦖 Draftosaurus - Sistema de Seguimiento y Juego Digitalizado

Este proyecto consiste en una aplicación web que permite **seguir y jugar partidas del juego de mesa Draftosaurus en su modo base**, ofreciendo una experiencia fiel a las mecánicas originales del juego físico. La herramienta se divide en dos modos de funcionamiento: **seguimiento** y **juego digitalizado**, desarrollados con tecnologías web modernas.

---

## 🎯 Objetivo del Proyecto

> Digitalizar el seguimiento y la jugabilidad del juego *Draftosaurus*, permitiendo a los jugadores registrar la colocación de dinosaurios, calcular la puntuación automáticamente y jugar partidas completas de forma local.

---

## 🧩 Modos de Uso

### 1. 📋 Modo Seguimiento
Permite a los jugadores registrar manualmente la colocación de dinosaurios y calcular automáticamente la puntuación al finalizar la partida.

**Características:**
- Ingreso manual de especies por recinto.
- Validación de reglas de colocación.
- Cálculo automático de puntajes y bonificaciones.
- Determinación del jugador ganador.

### 2. 🎮 Modo Juego Digitalizado
Permite jugar partidas completas desde la app simulando el juego físico.

**Características:**
- Selección aleatoria y paso de dinosaurios entre jugadores.
- Lanzamiento de dado con restricciones automáticas.
- Colocación dinámica de dinosaurios en los recintos.
- Control de turnos y rondas.
- Validación automática de todas las reglas.

---

## ⚙️ Tecnologías Utilizadas

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla), Bootstrap 5.3
- **Backend**: PHP 8.x
- **Base de Datos**: MySQL / MariaDB
- **Entorno de Desarrollo**: XAMPP 8.x
- **Entorno de Producción**: LAMP (GNU/Linux)
